# Security Policy

Do not report credentials, Telegram session files, Bale bot tokens, or private channel identifiers in public issues.

For a security report, contact the repository owner privately through the contact method listed on the GitHub profile. Include the affected version, reproduction steps, impact, and a minimal proof of concept without real credentials.

Before sharing logs, remove values from `API_HASH`, `BALE_BOT_TOKEN`, phone numbers, channel IDs, and any session-related content.
